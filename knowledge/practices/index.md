# Practices

* [Vertical Slices](vertical-slices.md) - Implementation tasks deliver small, independently verifiable increments of behaviour.
* [Testing Strategy](testing-strategy.md) - Which test layer owns which behaviour, and the fixtures and checks each relies on.
* [Error Handling](error-handling.md) - How failures are scoped, reported, and kept from becoming silent data loss or false completeness.
* [Logging and Redaction](logging-and-redaction.md) - Structured logging that is useful for diagnosis and safe to share.
* [Configuration](configuration.md) - Explicit, validated settings with safe defaults, where a missing value never widens access.
* [Dependency Policy](dependency-policy.md) - Keep the dependency set small, optional where possible, pinned, and audited.
* [Writing Knowledge](writing-knowledge.md) - Section, lifecycle, and wording rules that keep a knowledge concept self-contained, checkable, and free of delivery vocabulary.
