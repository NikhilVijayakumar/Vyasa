# Rendered design critique

Project adaptation informed by [Anthropic design-critique](https://github.com/anthropics/knowledge-work-plugins/blob/main/design/skills/design-critique/SKILL.md), reviewed 2026-10-22. Not a vendored upstream package.

Review the actual slice against the task, approved visual reference and relevant component contract. Inspect hierarchy, task clarity, action emphasis, density, consistency and accessibility. Separate observed defects from preference and unavailable evidence.

Record findings in the existing verification record:

Include successful decisions worth preserving. Still images cannot verify keyboard operation or animation. Inspect those interactions separately and record access limits. Resolve material findings before requesting maintainer review; agent critique never grants visual approval.
