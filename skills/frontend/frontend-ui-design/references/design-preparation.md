# Design-to-implementation preparation

Project adaptation informed by [Anthropic design-handoff](https://github.com/anthropics/knowledge-work-plugins/blob/main/design/skills/design-handoff/SKILL.md), reviewed 2026-10-22. Not a vendored upstream package.

Before code, complete the existing OpenSpec design with:

- Reference evidence, access limits and proposed project adaptations.
- Component exports, selected defaults/variants and controlled-state responsibilities.
- Token references, responsive behavior and local overflow.
- Loading, missing data, errors, long localized content and recovery.
- Interaction triggers, motion roles and reduced-motion alternatives.
- Keyboard/focus duties and applicable verification evidence.

Put reviewable slices and unresolved dependencies in tasks.md. Reuse durable component contracts rather than copying them. Do not create another lifecycle artifact, duplicate token values, fabricate measurements or require Figma when repository/browser evidence suffices.
